It's the big release week with Python 3.15.0 due out tomorrow, but before then, here's a full sweep of 3.10-3.14 security releases.

* This is an expedited release for 3.14 and 3.13, which come with binary installers.

* 3.12, 3.11 and 3.10 are in security-fix-only mode with no pre-set release cadence, and are source-only releases.
