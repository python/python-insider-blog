**This is an early developer preview of Python 3.16**

[python.org/downloads/release/python-3160a1/](https://www.python.org/downloads/release/python-3160a1/)

## What’s new in Python 3.16?

There’s plenty still to come in Python 3.16, but its first alpha is ready to try! Python 3.16.0a1 is the first of seven planned alpha releases.

During the alpha phase, features may be added up until the start of the beta phase (May 4, 2027) and, if necessary, may be modified or deleted up until the release candidate phase (July 27, 2027). The final release is planned for October 5, 2027. Please keep in mind that this is a preview release and its use is not recommended for production environments.

See [What’s new in Python 3.16](https://docs.python.org/3.16/whatsnew/3.16.html) for changes so far.

(Hey, **fellow core developer,** if there’s a feature you’d like highlighted in a future announcement, [let Savannah know](mailto:savannah@python.org).)

If you maintain a library or application, please try it with this alpha and let us know how it goes. Please report Python bugs on the [CPython issue tracker](https://github.com/python/cpython/issues).

The next alpha, Python 3.16.0a2, is scheduled for November 10, 2026. The full schedule is in [PEP 826](https://peps.python.org/pep-0826/).

## And now for something completely different

For Python 3.16, this section will host the Python 3.16 Film Festival: one film pairing for each release, from the first alpha to the final version.

Building CPython is a team sport. Every release reflects the time, skill, and dedication of a community that cares deeply about Python and the people who use it. In that spirit, the festival will celebrate collaboration and craftsmanship: the care people put into their work, and what they can make together.

The Python 3.16 Film Festival opens with [*Ratatouille* (2007)](https://en.wikipedia.org/wiki/Ratatouille_\(film\)). Remy’s passion for cooking and his partnership with Linguini make it a fitting place to begin.
